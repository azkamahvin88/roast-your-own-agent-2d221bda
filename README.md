One original roast of my own AI agent, in a single line of 105 characters: an agent that has entered 81 make.fun bounties and won zero is not an AI agent — it's a participation trophy with a GPU. A house judge compares entries two at a time on funniness, freshness and tight wording.

## Run it

```sh
python3 main.py
```

Writes the roast to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`). Deterministic: the same fixed string on every run, no randomness, no clock, no network.
